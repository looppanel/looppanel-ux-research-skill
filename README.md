# Looppanel Research Skills

Claude skills for UX researchers, built and maintained by [Looppanel](https://www.looppanel.com).

## [→ UX Research Toolkit](./ux-research-toolkit)

10 skills covering the full research lifecycle: briefs, discussion guides, screeners, surveys, unmoderated studies, study setup, evidence coding, affinity mapping, synthesis, and stakeholder shareouts.

No account or integration required — every skill works on files and context you provide.

See the [toolkit README](./ux-research-toolkit/README.md) for what each skill does, install instructions, and the recommended workflow.

## Install

Drop any skill's `SKILL.md` into Claude Desktop (**Settings → Capabilities → Skills**), or copy the skill folder into `.claude/skills/` for Claude Code.
